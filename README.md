# FDE AI Toolkit
Ready-to-use AI agent scaffolds, industrial digital solutions and development toolkits for developers and enterprise teams.

## Overview
This repository contains a series of standardized, out-of-the-box AI digital products and code templates, focusing on industrial intelligence, general AI agent development, and quantitative trading scenarios. All products are pre-built with complete documentation, designed to help users quickly deploy AI capabilities without custom development.

## Core Product Matrix

### 1. Industrial AI Solutions
Standardized digital toolkits for discrete manufacturing and industrial operation scenarios:
- **AI MES / PLM Templates**: Pre-built production management and product lifecycle management AI modules
- **APS Advanced Scheduling System**: Ready-to-use production scheduling framework with algorithm modules
- **Physical AI Toolkit**: Industrial scene AI perception and analysis code packages
- **Supply Chain AI Tools**: Demand forecasting and supply chain optimization solution templates
- **Discrete Manufacturing PM Suite**: Predictive maintenance and equipment management AI templates

### 2. General AI Agent Scaffolds
One-click deployable AI agent development frameworks and basic components:
- **AI Agent Platform Scaffold**: Full-stack agent development framework with multi-model access
- **FDE Agent Builder**: Visual agent configuration and workflow orchestration toolkit
- **Skill Library: Pre-built general skill modules for AI agents, covering office, data processing and analysis scenarios
- **AI Transit Station: Multi-model routing and API management middleware
- **WorkBuddy Suite: Office efficiency AI agent template set

### 3. AI Quantitative Trading Toolkit
Standardized quantitative trading research and backtesting tools:
- Full-market data access and processing modules
- Backtesting framework and strategy template library
- AI factor mining and strategy optimization tools
- Simulated trading operation supporting toolkit

### 4. AI Learning & Practice Resources
Systematic AI introductory and practical material packages:
- AI for Absolute Beginners: Zero-based introductory tutorial and practical cases
- Agent Usage Tips & Skill Manual: Detailed operation guide and best practices
- Claude / LLM Practical Skill Library: Prompt engineering and application case set
